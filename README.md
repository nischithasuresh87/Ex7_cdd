# Experiment 7: Automating Build and Testing Using GitHub Actions

## Objective
To automate the build and testing process of a Python application using GitHub Actions.

## Tools Used
- Python
- pytest
- Git and GitHub
- GitHub Actions
- Visual Studio Code

## Project Description
This project demonstrates Continuous Integration (CI) by automatically running Python tests whenever changes are pushed to GitHub.

## Application
A simple calculator program with automated tests using pytest.

The GitHub Actions workflow completed successfully.
